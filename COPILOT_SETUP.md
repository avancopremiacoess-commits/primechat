# Configurar o GitHub Copilot

Estas instruções mostram como ativar e usar o GitHub Copilot no Visual Studio Code.

1. Ativar o Copilot na sua conta GitHub
   - Acesse https://github.com/settings/copilot com sua conta do GitHub logada. Se ainda não tiver assinatura, você pode ativar o plano gratuito (Copilot Free), que já dá uma cota mensal de sugestões sem custo.

2. Instalar o VS Code
   - Baixe e instale o Visual Studio Code: https://code.visualstudio.com

3. Instalar a extensão no VS Code
   - No VS Code, clique no ícone de Extensões na barra lateral esquerda, pesquise por "GitHub Copilot" e clique em "Instalar" na extensão oficial publicada pela GitHub (o Copilot Chat costuma vir incluído).

4. Fazer login e autorizar
   - Depois de instalar, aparecerá um aviso no canto inferior pedindo login. Clique em "Sign in to GitHub", autorize no navegador que abrir e volte ao VS Code. O editor reconhecerá automaticamente sua assinatura (gratuita ou paga).

5. Testar o Copilot
   - Abra qualquer arquivo de código (por exemplo, um dos arquivos do painel do projeto) e comece a digitar — o Copilot deverá sugerir trechos de código automaticamente.
   - Para conversar com ele, use o ícone de chat na barra lateral ou o atalho Ctrl+Alt+I (Cmd+Alt+I no Mac).
